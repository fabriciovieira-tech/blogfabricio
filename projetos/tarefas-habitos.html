Sobre a aplicação

Ferramenta PWA focada no princípio de consistência diária ininterrupta (streak loop). Permite gerenciar micro-hábitos por categorias, acompanhar o mapa de calor dos últimos 14 dias com feedback sonoro ao realizar check-ins, zerar sequências individualmente e exportar métricas de desempenho para planilhas CSV.

Tecnologias: TypeScript / JS IndexedDB (Dexie.js) Web Audio API PWA Tailwind

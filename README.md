# 🚀 Projeto - Blog & Portfólio de Fabricio Vieira

Bem-vindo ao repositório do portal **Serra Tecnologia**, um ambiente web moderno, dinâmico e responsivo desenvolvido para apresentar projetos interativos, dashboards de alta performance, experimentos visuais em WebGL e artigos técnicos originais.

O projeto foi arquitetado com foco em performance, experiência do usuário (UX) e design limpo, unindo aplicações dinâmicas e leituras imersivas em um único ecossistema.

---

## 🛠️ Tecnologias Utilizadas

### **Front-end & Interface**
* **HTML5 & CSS3:** Estruturação semântica e estilização customizada com tipografia *Inter*.
* **Tailwind CSS (v4):** Framework utilitário para layout fluido, responsividade e temas escuros.
* **Three.js & WebGL:** Renderização de fundo interativo com simulação de partículas tridimensionais.
* **GSAP (GreenSock):** Animações suaves de transição entre subpáginas e visões.

### **Projetos Integrados (Micro-Frontends & Web Apps)**
* **Vue.js 3:** Reatividade e gerenciamento de estado na UI dos utilitários.
* **Chart.js:** Visualização de dados dinâmicos e gráficos financeiros em tempo real.
* **Dexie.js / IndexedDB:** Persistência de dados local no navegador (100% offline).
* **API do Banco Central do Brasil (BCB):** Integração para consulta automatizada do CDI oficial.

## 🌟 Principais Funcionalidades

* **Leitor de Artigos Imersivo:** Leitura limpa e centralizada inspirada nos padrões do G1 e Medium, otimizada para legibilidade e sem distorção de imagens em telas mobile e desktop.
* **Integração de Micro-Frontends:** Execução de aplicações completas (Dashboards, E-commerce e Monitor de Redes) via iframes de alta performance e isolamento de escopo.
* **Persistência de Dados e PWA:** Aplicações integradas que armazenam históricos e configurações diretamente no IndexedDB do usuário.
* **Experiências Visuais em 3D:** Fundo estrelado interativo renderizado via canvas WebGL sem comprometer a taxa de quadros (FPS).

## 💻 Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone [https://github.com/seu-usuario/blogfabricio.git](https://github.com/seu-usuario/blogfabricio.git)
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd blogfabricio
   ```
3. Abra o arquivo `index.html` em seu navegador de preferência ou utilizando a extensão **Live Server** no VS Code.
